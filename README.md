### Praca magisterska - repozytorium

#### Treść zagadnienia

Modelowanie zainteresowania zarządzanym produktem w oparciu o zmienne zależne (tj. kontrolowane przez użytkownika, np. cena) i niezależne (np. warunki klimatyczne) oraz wykorzystanie uzyskanych informacji o owym zainteresowaniu do odnalezienia optymalnej strategii cenowej.

Repozytorium zawiera 

(1) skrypty umożliwiające przeprowadzanie symulacji związanych z treścią pracy, 

(2) dane wykorzystywane do symulacji, 

(3) opisy różnych podejść do głównych zagadnień,

(4) artykuły/książki związane z tematem.
